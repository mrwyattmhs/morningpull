GitHub & GitHub Actions

New REST API endpoint returns deprecation dates for runner versions (GET /actions/runners/deprecations/{version}), with response fields runner_version, runtime_deprecates_at, and registration_deprecates_at for planning upgrades.

Added vulnerability-alerts permission for GITHUB_TOKEN, supporting read and none values for read-only Dependabot alert access following least-privilege principles.

Four new job context properties (job.workflow_ref, job.workflow_sha, job.workflow_repository, job.workflow_file_path) let reusable workflows determine their own source identity at runtime. Note: not available on GitHub Enterprise Server.

Starting October 1, 2026, checks, workflow runs, and statuses will follow Actions retention settings (default 90 days) instead of the previous 400+ day default, automatically cleaning up once they exceed configured artifact/log retention.

CodeQL 2.26.4 released with Go 1.27 support, improved Rust alert locations, and broader accuracy improvements across C#, Java/Kotlin, Python, JavaScript, TypeScript, and GitHub Actions security detections.

Python Tooling

uv (Astral's Rust-powered package manager) is now overtaking pip in CI usage for major projects (Wagtail: 66% uv vs 34% pip).

uv is a Python package manager and project manager written in Rust that replaces pip, venv, virtualenv, pip-tools, pyenv, and optionally poetry—10-100x faster than pip.

Python tooling convergence: uv replaces pip+venv+poetry, Ruff replaces black+flake8+isort, mypy for types.

Python 3.14 shipped template strings (PEP 750), deferred annotation evaluation (PEP 649), an experimental JIT, sub-interpreters in stdlib (PEP 734), and Sigstore-only signing (PEP 761).

CPython 3.14 supports free-threading officially, making parallel execution much more practical for selected workloads.

Claude Sonnet 5 introductory pricing ($2/$10 per MTok) now becomes standard; planned September 1 increase cancelled.

Content API for Shopping will experience progressive errors starting September 1, 2026; apply for extended access to migrate to Merchant API.

Space & science

Top Science News — Space, Physics & Engineering

SPACE

Japan's JAXA Martian Moon eXploration (MMX) mission is heading to Mars and Phobos next month to collect samples from Phobos and return them to Earth. This is significant as the first sample return from a Martian moon, offering insights into the moon's composition and origin.

Astronomers using JWST discovered that massive early galaxies contain far more small, faint stars than expected, potentially making some of these galaxies three to four times more massive than previously thought. This challenges models of galaxy formation in the early universe.

Astronomers have taken one of the deepest looks yet at Cloud-9, a candidate "dark galaxy," and found no trace of stars. Dark galaxies—if they exist—could represent an entirely new class of galactic structures.

Researchers at UCSB and UT Austin determined that a galactic merger kicked a supermassive black hole into intergalactic space. This is rare observational evidence of black hole ejection through gravitational interactions.

PHYSICS

Physicists have directly observed a long-predicted quantum effect of gravity, putting one of Einstein's foundational ideas to a striking new test. This represents experimental confirmation of quantum gravity predictions.

The LUX-ZEPLIN dark matter experiment detected a rare particle interaction that looks unusually difficult to explain as ordinary background noise and appeared where dark matter might be expected. The signal remains unexplained and could represent new physics.

A major new analysis finds that the evidence for cosmic acceleration remains strong, preserving the leading role of dark energy. This contradicts recent claims that expansion was slowing.

ENGINEERING

MIT engineers combined living muscle tissue with 3D-printed robotic frames to create biohybrid robots that can swim, crawl, and self-repair using nutrient fluids, with potential surgical and disaster response applications.

A self-healing asphalt pilot in the Netherlands uses conductive fibers and induction-based heating, showing pothole formation reduced by 50% with less need for resurfacing. This could extend road lifespans and reduce maintenance costs.

Engineers transformed a brittle cobalt-aluminum compound into a material up to 10 times stronger than steel that can bend without breaking. This addresses the longstanding brittleness problem in high-strength materials.
