Developer tools & automation

GitHub & GitHub Actions

New REST API endpoint (GET /actions/runners/deprecations/{version}) returns when registration and runtime support end for runner versions, available at repository, organization, or enterprise level. Response includes runner_version, runtime_deprecates_at, and registration_deprecates_at.

New vulnerability-alerts permission for GITHUB_TOKEN grants workflows read-only access to Dependabot alerts using least-privilege practices instead of broader scopes.

Four new job context properties (job.workflow_ref, job.workflow_sha, job.workflow_repository, job.workflow_file_path) let reusable workflows determine their own source identity at runtime. Not available on GitHub Enterprise Server.

Environments now work without automatic deployments: configure with deployment: false key to access environment secrets and variables without creating new deployments.

Python Tooling

uv building toward vulnerability scanning for globally installed CLI tools; preview feature in 0.11.25 writes lockfile for each tool installed.

PEP 828 accepted August 3: adds yield from support inside async generators starting in Python 3.16, with StopAsyncIteration now carrying a .value attribute.

AWS Lambda's Python 3.12+ runtimes feature SnapStart, reducing cold starts from ~2,000ms to 200ms.

Python 3.14 adds safe external debugger interface (PEP 768) enabling more stable IDE/debugger integration.

Tools uv and pixi written in Rust provide unified dependency management rivaling npm/cargo simplicity.

API Development & Testing

Shift toward tools treating API definitions as first-class citizens in development lifecycle rather than auxiliary artifacts managed separately from code.

Treating API collections as code: storing as human-readable files (YAML/JSON) in source control, subject to same versioning, code review, and CI/CD practices as application source code.

Bruno stores collections as plain-text files in Git repository, designed for teams that review API changes like code.

Postman added MCP protocol support enabling interaction with API collections through AI clients.

Open-source tools (oasdiff) and Postman offer breaking-change detection that runs in CI and fails on breaking differences.

AI-enabled API test generators catch 41% more post-deployment bugs vs. manual scripting; generate contract tests, negative tests, and auth checks on every build.
